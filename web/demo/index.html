De lelievlet in je eigen pagina

Het 3D-model van de lelievlet is een kleine bibliotheek. Je zet een element op je pagina, geeft het een hoogte, en laat de bibliotheek er een viewer in bouwen. De viewer staat in een eigen shadow DOM: jouw stijlen raken hem niet en zijn stijlen raken jouw pagina niet.

<div id="vlet" style="height:600px"></div>
<script type="module">
  import Lelievlet from 'https://wiebren.github.io/lelievlet/lelievlet.js';
  Lelievlet.create(document.getElementById('vlet'), {
    aanpassen: { zeilnummer: '442', naam: 'Fluessen', plaats: 'Zwolle' },
    namen: { onderdelen: { hommerring: 'Mastring' } },
    quiz: { niveau: 2 },
  });
</script>

Alles in de configuratie is optioneel. Wat je weglaat blijft zoals de viewer het zelf heeft. De volledige lijst met instellingen staat in de README.

Twee viewers op één pagina

Ze weten niets van elkaar: een keuze in de ene verandert niets in de andere. De linker is de standaardviewer; de rechter heeft andere kleuren, een ander zeilnummer, een hernoemd onderdeel, Oefenen op CWO I en de debug-hulpjes aan.

Wat de viewer teruggeeft

const vlet = Lelievlet.create(element, { … });
await vlet.ready;     // het model is geladen en het eerste beeld staat er
vlet.config;          // de configuratie zoals hij geldt, met alle standaardwaarden ingevuld
vlet.destroy();       // stopt de viewer, geeft het WebGL-geheugen terug en maakt het element leeg
