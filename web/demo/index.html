De lelievlet in je eigen pagina

Het 3D-model van de lelievlet is een kleine bibliotheek. Je zet een element op je pagina, geeft het een hoogte, en laat de bibliotheek er een viewer in bouwen. De viewer staat in een eigen shadow DOM: jouw stijlen raken hem niet en zijn stijlen raken jouw pagina niet.

<div id="vlet" style="height:600px"></div>
<script type="module">
  import Lelievlet from 'https://wiebren.github.io/lelievlet/lelievlet.js';
  Lelievlet.create(document.getElementById('vlet'), {
    aanpassen: { zeilnummer: '442', naam: 'Fluessen', plaats: 'Zwolle' },
    namen: { onderdelen: { hommerring: 'Mastring' } },
    quiz: { niveau: 2 },
  });
</script>

Alles in de configuratie is optioneel. Wat je weglaat blijft zoals de viewer het zelf heeft. De volledige lijst met instellingen staat in de README.

Of in een iframe

Heeft je site ingelogde gebruikers, zet de viewer dan in een iframe: hij draait dan op deze site en kan niets van jouw pagina zien of aanraken. De configuratie komt na de #, als JSON. Wat create() teruggeeft kun je dan niet gebruiken; meer in de README.

<iframe src='https://wiebren.github.io/lelievlet/embed.html#{"aanpassen":{"zeilnummer":"442"},"quiz":{"niveau":2}}'
        style="width:100%; height:600px; border:0"
        sandbox="allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox"
        allow="fullscreen" title="3D-model van de lelievlet"></iframe>

Twee viewers op één pagina

Ze weten niets van elkaar: een keuze in de ene verandert niets in de andere. De linker is de standaardviewer; de rechter heeft andere kleuren, een ander zeilnummer, een hernoemd onderdeel, Oefenen op CWO I en de debug-hulpjes aan, en begint van boven gezien in Roeien met vier riemen.

Wat de viewer teruggeeft

const vlet = Lelievlet.create(element, { … });
await vlet.ready;     // het model is geladen en het eerste beeld staat er
vlet.config;          // de configuratie zoals hij geldt, met alle standaardwaarden ingevuld
vlet.destroy();       // stopt de viewer, geeft het WebGL-geheugen terug en maakt het element leeg
vlet.fullscreen();    // volledig scherm aan/uit (alleen vanuit een klik of toets van de gebruiker)
vlet.get();           // de toestand waarin de viewer nu staat
vlet.set({ modus: 'roeien', commando: 'slag' });   // naar een andere toestand, geanimeerd

Waar de viewer begint, geef je mee als toestand, met dezelfde sleutels:

Lelievlet.create(element, {
  toestand: { modus: 'zeilen', koers: -135, reven: 1, aanzicht: 'zij', selectie: 'hommerring' },
});
